# Screenshot capture brief

The README references six files in this directory. Until they land, those image
links render broken on GitHub. Capture them in one pass with a real class
running, two browsers side by side, and ink already on the board.

| File | What it shows | Browser | Width |
|---|---|---|---|
| `classroom-desktop.png` | Hero shot. Teacher view: board centre stage with ink on it, video rail alongside, control bar below | Teacher | 1440 |
| `whiteboard-student.png` | Student's read-only board. Toolbar absent, zoom menu open | Student | 1440 |
| `lobby-knock.png` | Teacher's knock queue with at least one student waiting | Teacher | 1440 |
| `chat-hands.png` | Side panel showing chat messages and a raised hand | Teacher | 1440 |
| `recordings.png` | Recordings list with the in-browser player open | Teacher | 1440 |
| `mobile-classroom.png` | Phone layout: MobileStrip, board, phone control bar | Student | 390 |

Notes for the capture pass:

- The board needs a minimum of 900 x 506 to be usable, and has a hard floor at
  800 wide. Below that a shot misrepresents the product.
- Put real handwriting on the board before any shot that includes it. An empty
  canvas reads as a broken feature.
- Use plausible names and a plausible class title. No placeholder text.
- Save as PNG. Keep each file under about 500 KB so the README stays quick to
  load.
